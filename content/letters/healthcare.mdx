# 体测与就医：评分标准与医保报销

大学四年，体测和生病是绕不开的事。这份指南帮你把体测怎么拿分、去哪看病、医保怎么报销一次讲清楚。

---

## 一、体测评分与拿分策略

### 评分标准

体测**总分100分加上附加分20分**，满分120分。

- **60分**是毕业底线
- **80分**以上才算良好
- 想拿奖学金或评三好学生得冲到**90分以上**

### 各项目评分

| 项目 | 分值 | 拿分技巧 |
|------|------|----------|
| BMI | 15分 | 男生17.9-23.9、女生17.2-23.9是满分区间，太胖太瘦都扣分 |
| 肺活量 | - | 属于容易拿分的项目，只想及格的同学把这两项吃透就行 |
| 坐位体前屈 | - | 容易拿分 |
| 长跑（男1000/女800） | 附加分 | 男生1000米和引体向上、女生800米和仰卧起坐，每项最多加10分 |
| 力量项目 | 附加分 | 想冲高分的同学这两项不能摆烂 |

### 实测小技巧

#### 肺活量

1. 先深呼吸两三次
2. 鼻子吸满一口气再屏住
3. 嘴巴张开再补吸一口
4. 吹的时候**仰头不要低头**
5. 吹到胸腔回收时弯腰还能挤出余气
6. **别断吹别漏气**，准备好了再开始

#### 800米（女生）

1. **稳起跑**——抢完道之后跟着前面的人跑
2. **匀途中**——弯道匀速，直道加速超人
3. **狠冲刺**——最后100米加大摆臂冲刺

#### 仰卧起坐

1. 不要抱头，双手轻搭耳朵两侧
2. 靠腹部收缩发力
3. 肩膀过耳垂就算合格，不用完全坐直
4. 如果用电子腰带测量，腰带字朝上戴在胸部以下、肚脐往上的位置，避免少计数

#### 立定跳远

关键在摆臂：起跳前手臂后摆时稍微往上提一点，再用力抡出去，能明显感受到向前的惯性。有同学用这个方法多跳了十几厘米。

## 二、校医院在哪、能看什么

校医院离平苑宿舍比较近，住平苑的同学走几步就到。

### 能看什么

- **感冒发烧**这类常见病在校医院就能解决
- 付款时直接刷校园卡或医保电子凭证结算
- 医保自动报销，自付部分通常很少

### 能力边界

校医院的能力边界也要心里有数：
- **牙科等科室校医院没有**
- **皮肤问题或者需要拔智齿**这类情况，得转诊到校外

**安徽理工大学第一附属医院**分南区和北区：
- **南区**：有皮肤科专家门诊
- **北区**：口腔科可以处理阻生齿

有同学分享过在北区拔智齿的经历——需要提前联系医生、拍片，打麻药有点痛但拔的过程不痛，**一颗阻生齿拍片加拔牙加吊水下来大概一千多元**（以医院实际收费为准，仅作参考）。

## 三、医保报销怎么用

### 什么是大学生医保

每年交几百块的**大学生医保属于城乡居民医保**，按年缴费。医保卡查不到余额是正常的，因为大学生医保账户里本来就没有钱，但不影响统筹报销。

### 校内就医

最简单：挂号、看诊、开药，缴费时自动走医保报销，只付自付部分，基本花不了多少钱。

### 校外就医

多一步流程：

1. **先去校医院挂号**让医生开转诊单
2. 去定点医院就诊，告诉医生用大学生医保
3. 看完病把以下材料全部留好：
   - 挂号记录
   - 病历
   - 发票
   - 药品清单
   - 转诊单

4. 回校后按学校通知的时间集中报销

> ⚠️ **发票只能打印一次**
> 
> 校外医院的发票在自助机上只能打印一次，丢了补不了。看完病第一时间打印并收好，这是报销的核心材料。

### 异地就医

寒暑假或实习期间在外地看病：

1. **提前在校医院报备**异地就医
2. 同时在支付宝或微信搜「异地就医备案」完成线上备案
3. 备案后在当地联网医院可以直接结算
4. 没备案的话可能少报甚至不报

> 📌 异地就医同样要保存好所有票据，回校后走报销流程。

### 注意事项

不同地区的大学生医保政策差异挺大，有的省份门诊也能报，有的省份校外门诊只报住院部分。**具体报销比例和限额以学校当年发的通知为准**，入学后留意辅导员或班群发的医保相关文件。

<Aside tone="tip" title="一句话总结">

总的来说，小病尽量在校医院解决，省事也省钱。需要转诊的话记住「先开转诊单、保存所有票据」这两个关键动作，报销流程虽然有点繁琐，但该拿回来的钱别白白丢掉。

</Aside>
