这是一份可以照着执行的安理大新生路线图：**离家前准备什么、报到当天先去哪、宿舍安顿后做什么、第一周怎样不漏通知**。原来的《大一新生手册》和《开学第一周》已经合并到这一页，避免你在两篇文章之间反复跳转。

先记住一个总原则：**日期、缴费金额、账号规则和材料要求，每年都可能调整。录取通知书、数字迎新系统、今日校园和辅导员当年通知，优先级高于任何攻略。**

<Aside tone="info" title="一分钟路线图">

```text
离家前：核对官方通知 → 整理证件档案 → 登录迎新系统 → 缴费与住宿
报到日：学院报到点 → 领卡与材料 → 宿舍入住 → 检查设施
前 72 小时：校园卡/网络/应用 → 班会 → 课表与校历 → 防骗
第一周：跑通教学系统 → 建立通知清单 → 熟悉校园 → 只选少量社团
```

</Aside>

## 一、离家前：先把信息源收拢

开学最容易出错的不是少带一瓶洗发水，而是从非官方群聊里拿到一条过期通知。建议把下面几个入口加入浏览器收藏夹：

| 入口 | 用途 |
| --- | --- |
| [本科招生网·新生指南](https://zs.aust.edu.cn/xszn.htm) | 新生须知、报到信息 |
| [数字迎新系统](https://yx.aust.edu.cn/stusv-estudent-main/) | 学号、缴费、迎新流程等 |
| [智慧校园](https://i.aust.edu.cn/) | 校内服务聚合入口 |
| [教务处](https://jwc.aust.edu.cn/) | 校历、教学与考试通知 |
| [教务系统](https://jw.aust.edu.cn/) | 课表、选课、成绩 |
| [一卡通服务](https://ykt.aust.edu.cn/) | 充值、余额、挂失 |
| [校园网自服务](https://drcom.aust.edu.cn/) | 校园网账号与流量 |
| [图书馆](https://lib.aust.edu.cn/) | 馆藏、座位与数据库 |

再建立一个简单的“开学任务表”，每条只写四项：**任务、截止日期、通知来源、是否完成**。群消息只负责提醒你，任务表才负责让你不漏事。

### 只认这三类通知

1. 学校、学院官网和官方系统发布的通知；
2. 辅导员、助导在实名班级群发布的通知；
3. 录取通知书随附材料。

任何让你私下付款、扫脸、提交身份证正反面或下载陌生 App 的消息，都先停一下，向辅导员核实。

## 二、证件、档案与行李：三层打包法

### 第一层：随身证件袋

- 录取通知书、身份证及必要复印件；
- 一寸、二寸证件照和电子版；
- 团组织关系、户口迁移等与你有关的材料；
- 助学贷款回执及资助申请材料；
- 录取通知书明确要求的其他文件。

证件袋随身携带，不放进托运行李。把关键材料扫描成 PDF，存一份到自己可控的云盘或加密设备里。

### 第二层：密封档案

纸质学籍档案不要自行拆封。档案究竟由高中统一寄送、学生自带，还是通过指定渠道转递，应向原高中和录取学院确认。若需要寄送：

- 只使用学院当年公布的收件地址和收件人；
- 快递面单备注姓名、学院等必要信息；
- 保存面单照片和物流签收记录；
- 到校后按学院安排确认是否归档。

不要照抄往届群里的收件人姓名。老师和负责窗口可能变化。

### 第三层：生活行李

行李原则是：**证件随身、药品够用、大件少带、违禁电器不带**。

- 带一周换洗衣物、常用药、雨具、充电器和一套应急洗漱用品；
- 被褥尺寸先看当年宿舍说明，大件可以到校购买或按规定寄送；
- 不带热得快、电煮锅等宿舍明令禁止的电器；
- 贵重设备不离身，行李箱贴姓名和电话时注意遮挡部分号码。

## 三、迎新系统：按顺序做，不抢跑

迎新流程通常存在前后依赖，可以理解为：

```text
确认身份与学号 → 阅读缴费说明 → 完成相应流程 → 查看住宿安排 → 到校核验
```

具体开放时间和功能以当年系统为准。操作前先读页面说明，再确认提交；高峰期卡顿时，不要多设备反复登录或连续点击付款。

### 缴费与绿色通道

无助学贷款的同学按官方缴费入口办理；办理助学贷款或暂时存在经济困难的同学，先阅读当年的“绿色通道”和资助说明，不要因为着急而在非官方链接付款。

每次付款后保存订单号和截图，但截图不要发到公开群。发现金额、学号或状态异常，联系学校公布的财务或迎新咨询渠道。

### 宿舍安排

有的年份支持线上选择，有的年份由学院统一分配。不要把往届的开放时间、床位朝向经验当作本届规则，更不要向陌生人支付所谓“代抢费”。入住后再根据实际空间购买收纳用品，通常比报到前盲买更省钱。

## 四、报到当天：按四个节点走

1. **找到学院迎新点**：核验身份、提交当年要求的材料；
2. **领取资料与卡片**：现场逐项核对姓名、学院和使用说明；
3. **前往宿舍登记**：领取钥匙，确认床位和宿舍管理要求；
4. **检查宿舍设施**：对门锁、床架、插座、照明、空调等拍照留档，有问题及时报修。

如果独自报到，不必焦虑。官方迎新点和志愿者会提供路线帮助；但行李、手机和证件始终由自己或可信任的同伴看管。

### 报到日防骗清单

- 宿舍内推销的电话卡、培训课、床品和兼职，一律不当场付款；
- 任何“退款、补贴、账户异常”信息，先在官方系统核对；
- 不把验证码、银行卡密码、身份证照片发给他人；
- 加群先核实群主和管理员身份，警惕仿冒辅导员头像；
- 电话卡去正规营业厅办理，套餐细则留存截图。

## 五、前 72 小时：把校园基础设施跑通

### 1. 校园卡、银行卡和生活缴费

按现场说明激活校园卡并设置安全密码，了解充值、挂失和补办入口。银行卡是否随通知书发放、何时激活，以当年安排为准；不要因为排队而把身份证交给陌生“代办人员”。

### 2. 今日校园与校内应用

按学院通知安装并绑定应用。初始密码只从官方说明获取，首次登录后立即修改，避免姓名、生日、学号等弱密码。辅导员通知类应用建议保留推送权限。

### 3. 校园网

从学校入口确认账号和办理方式。路由器、运营商套餐和宿舍网络配置可能因楼栋不同而变化，先询问宿管或校园营业点，再购买设备。

### 4. 宿舍第一次会议

不需要很正式，十分钟说清四件事：卫生轮值、作息与灯光、公共用品费用、突发情况联系人。分歧越早说清楚，越不容易积成矛盾。

## 六、第一周：先建立一套不会漏事的系统

### 教务系统至少登录一次

不要等选课截止前才发现登录失败。第一周完成：

- 修改初始密码并妥善保存；
- 对照教务处发布的当学年校历；
- 核对课表、教室、课程周次；
- 把考试、选课和网课截止日期加入日历；
- 发现缺课、重课或信息错误，及时向学院教学办或教务处咨询。

### 通知分成三级

| 级别 | 例子 | 处理方式 |
| --- | --- | --- |
| 必须当天看 | 辅导员、班级、教务通知 | 保持提醒，读完立即记截止日 |
| 每周集中看 | 学院活动、竞赛、讲座 | 周末筛选一次 |
| 可以静音 | 兴趣群、老乡群、商家群 | 不让它打断学习 |

### 用半天走完生活路线

自己走一遍教学楼、图书馆、食堂、操场、校医院、快递点和学院办公室。地图里“知道在哪”和赶课时“能走到”不是一回事。

### 社团先观察，再报名

百团招新时先问清活动频率、值班要求和费用。大一上学期先选 **1—2 个真正愿意持续参加的组织**，给课程、运动和独处保留时间。社团照片很热闹，但你的大学生活不需要靠报名数量证明。

## 七、军训与后续事项：看当年通知，不背往年日期

军训时间、服装、集合地点和免缓训材料每年可能变化。通用准备只有几项：合脚鞋垫、防晒、足量饮水、常用药；身体不适及时报告，不要硬撑。

后续常见事项包括安全教育、心理测评、困难生认定、团组织关系转接、体育选课、普通话考试和实验室安全准入。它们的共同处理方式是：

1. 收到通知当天看清对象、材料和截止时间；
2. 写进日历并预留至少一天缓冲；
3. 完成后保留提交成功页面；
4. 不确定时问发布通知的部门，而不是在非官方群里猜。

考虑转专业的同学，应查看目标学院当年的遴选细则。转入后可能涉及补修、退选和学分认定；教务处的 [2026 年转专业后续学籍提示](https://jwc.aust.edu.cn/info/1044/2984.htm) 也明确要求学生核对新培养方案与课表，因此不要只盯着“能不能转”，还要计算转换成本。

## 八、可截图保存的阶段清单

### 离家前

- [ ] 核对录取通知书与官方新生指南
- [ ] 证件、档案、资助材料分别整理
- [ ] 保存学院和辅导员的官方联系方式
- [ ] 完成迎新系统中已开放的项目
- [ ] 下载离线地图，告知家人行程

### 报到当天

- [ ] 学院报到并逐项核对领取材料
- [ ] 宿舍登记、检查设施、拍照留档
- [ ] 重要证件和付款凭证不发公开群
- [ ] 只在官方渠道办理卡、网和缴费

### 第一周

- [ ] 登录教务系统，核对校历与课表
- [ ] 建立“任务—截止日—来源”清单
- [ ] 跑通校园卡、网络与生活服务
- [ ] 走完一次教学和生活路线
- [ ] 与室友沟通作息、卫生和公共费用
- [ ] 社团先体验，只留下真正想参加的

<Takeaways title="真正值得记住的六句话">

- 官方通知永远高于往届攻略；
- 证件随身、档案不拆、付款留证；
- 初始密码不转发，登录后立刻修改；
- 截止日期进日历，不靠群消息记忆；
- 不懂就找通知发布部门，不向陌生人交钱；
- 第一周的目标不是把大学“玩明白”，而是建立自己的生活系统。

</Takeaways>
