# 大一新生生存手册

高中毕业，第一次远离父母独自生活。这份手册帮你把「大一刚开始要注意什么」一次性讲清楚。

---

## 一、开学报到

### 必带材料

- 录取通知书
- 身份证 + 复印件
- 高考准考证
- 档案（有些省份是电子档案，注意学校要求）
- 证件照（1寸/2寸蓝底白底都备几张）
- 团员证 + 团组织关系转接证明
- 银行卡

### 报到动线

1. **到校**：先找自己学院的帐篷（会有学长姐举牌接站）
2. **资格审查**：录取通知书 + 身份证
3. **领取物资**：校园卡、宿舍钥匙、一卡通
4. **入住宿舍**：去宿舍楼登记，领取被褥等
5. **班级群**：加班级群，认领辅导员和助导

<Aside tone="tip" title="小贴士">

报到当天人很多，能早去就早去。可以带个小包，把重要证件装一起，随用随取。

</Aside>

---

## 二、宿舍入住

### 房型一览

- **4人寝**：上床下桌，配空调（除平苑外都是）
- **6-8人寝**：部分老校区有
- **费用**：约800-1200元/学年

### 抢宿技巧

- 数字迎新系统开放选宿后尽快抢
- 选之前问学长姐：哪个楼新旧、哪个楼离教学楼近
- 一般上层比下层安静，但顶层夏天热

---

## 三、军训攻略

### 训练节奏

- **时长**：一般两周左右
- **内容**：站军姿、走正步、队列训练、拉歌
- **时间**：早上 + 下午，晚上可能有讲座或活动

### 装备避坑

| 推荐 | 不推荐 |
|------|--------|
| 舒适的运动鞋/军训鞋垫 | 新鞋（会磨脚） |
| 防晒霜（提前抹） | 金属框眼镜（暴晒会发烫） |
| 大容量水壶 | 紧身衣物 |
| 冰袖/防晒袖套 |  |

### 请假流程

- 身体不适及时报告教官
- 需要开证明的联系辅导员
- 不要硬撑，身体最重要

---

## 四、食堂美食

### 四大食堂

安理工有多个食堂，常见的有：

- **新区食堂**：选择多，装修较好
- **老区食堂**：价格实惠，味道经典
- 各学院小食堂

### 觅食建议

- 错峰吃饭：11:30 和 12:00 是高峰期
- 校门口也有小吃街，价格亲民
- 想省钱：食堂一荤一素约8-12元

---

## 五、社团与社交

### 社团招新

- **时间**：大战结束（9月中下旬）
- **常见社团**：吉他社、舞蹈社、志愿者协会、篮球队等
- **报名方式**：百团大战现场报名/面试

### 校院组织

- **学生会**：院学生会、校学生会
- **班委**：班长、团支书、学习委员
- **社团**：兴趣导向为主

<Aside tone="tip" title="加入社团的建议">

参加1-2个组织就够了，加多了忙不过来。社团是为了兴趣，不是为了综测加分。

</Aside>

### 大一融入

- 主动认识室友和同学
- 参加班级活动、破冰活动
- 加入同乡会（如果有）

## 六、运动与就医

### 体测评分

- 体测成绩计入体育课成绩
- 项目：50米、立定跳远、仰卧起坐/引体向上、长跑等
- 及格即可，但对评优有影响

### 校医院

- 校医院在校内，看病便宜
- 需要转诊单才能校外报销

### 医保报销

- 大学生医保开学后会统一办理
- 校医院看病可报销部分费用

---

## 七、大一必须知道的事

### 绩点很重要

- **综测、保研、奖学金、转专业**都看绩点
- 大一课程相对基础，是最容易拿高分的阶段
- 高数和线代是很多专业的基础，没跟上后面会很吃力

### 四六级越早考越好

- 大一英语底子还在，课余时间相对充裕
- 大二开始课业增加，再考会更累
- 有些学校大一不让考四级，具体看学校安排

### 选课技巧

- 热门课开放几分钟就被抢光
- 选之前问问学长姐：这门课给分怎么样、作业量大不大
- 体育课选喜欢的项目，手速要快

## 八、大一 checklist

- [ ] 关注学校官方公众号（教务处、学生处、各学院）
- [ ] 下好今日校园（辅导猫）
- [ ] 记住教务系统账号密码
- [ ] 加入班级群、年级群
- [ ] 了解自己专业的培养方案
- [ ] 制定大一绩点目标
- [ ] 搞定四六级报名
- [ ] 参加一次社团活动
- [ ] 至少认识5个新朋友
