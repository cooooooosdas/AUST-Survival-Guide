# 安徽理工大学完全指南

填志愿就这一次机会，很多同学对安理工的了解可能仅限于名字和分数线。这份指南来自小红书社区的经验分享，帮你把「这所学校到底怎么样」拆开看。

---

## 一、学校概览

### 基本信息

- **创办时间**：1945年，前身是淮南煤炭学院
- **性质**：省属公办理工类高校
- **校训**：「团结、奋进、博学、奉献」
- **位置**：安徽淮南

### 排名与实力

- 2026年软科中国大学排名第 **180 名**
- 校友会排名第 **246 名**
- 本科专业超过 **60 个**，覆盖工学、医学、理学、管理学等

**特色专业**：
- 安全工程（A级学科，行业认可度高）
- 采矿工程
- 地质工程
- 弹药工程与爆炸技术（全国少有）

<Aside tone="info" title="一句话总结">

学校不出名 ≠ 专业不强。安理工的安全科学、矿业工程在行业圈子里认可度扎实。

</Aside>

### 在校生体感

- **工科氛围浓**：课程紧凑，实验课占比高
- **校园生活安静**：淮南不是大城市，周边娱乐有限，但生活成本低
- **同学关系朴实**：不卷但也不散漫，互帮互助风气不错
- **独特记忆**：「爆破」写在学院名里，舜耕山就在校园边上

## 三、专业选择

### 热度分化

不同专业之间分差很大。以2025年安徽为例：
- 物理类 **005 组**（不限）最低566分/位次53805
- 物理类 **006 组**（选考化学）最低571分/位次48862
- 两者相差近 **5000 个位次**

### 热门方向

| 专业 | 体感 |
|------|------|
| **电气工程** | 校内公认的热门。就业面宽（电网、电力设计院、新能源），但课程难度不低 |
| **计算机类** | 报考热门，编程是硬门槛。课内中规中矩，想有竞争力需课外项目积累 |
| **临床医学** | 五年制，节奏和工科完全不同，背诵内容多 |
| **采矿/矿物加工** | 传统根基，师资深厚，但近年报考热度下降 |

### 关于调剂

> ⚠️ 服从调剂要想清楚两面：能保住学校，但可能被调到完全不感兴趣的方向，后续转专业竞争也激烈。

## 四、转专业

### 基本规则

- **窗口期**：大战结束（大一下学期春季）
- **基本门槛**：大一上学期绩点达到要求，且在本专业排名靠前
- **热门方向**：电气、计算机、临床医学竞争激烈，可能有笔试+面试

### 考核形式

- **笔试**：数学 + 英语
- **面试**：自我介绍 + 对新专业的认知

> 💡 面试时重点讲你为什么想去这个专业、做了什么准备，但别踩「贬低原专业」的坑。

<Aside tone="warn" title="提前准备">

想转专业，大一上学期就要开始准备：冲绩点 + 联系目标专业学长姐了解往年考核重点。

</Aside>

## 五、给不同目标同学的建议

| 你的目标 | 建议 |
|----------|------|
| **想进安全/矿业系统** | 直接报，优势明显 |
| **想进电网/电力** | 争取进电气专业，或大二转专业 |
| **想进互联网大厂** | 进计算机类专业，课外积累项目经验 |
| **想读研深造** | 建议选传统工科（安全、矿业），考研调剂有优势 |
| **不确定未来** | 先进来，大一转专业是二次机会 |
