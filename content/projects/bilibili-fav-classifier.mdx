## 收藏了很多，然后呢？

教程、音乐、游戏实况全堆在默认收藏夹里，想找的时候却翻不到。这个小工具把视频按规则分组，先生成分类计划，确认后再整理真实收藏夹。适合愿意在自己电脑上运行 Python 工具的同学。

项目归类：**效率工具 / 内容整理 / Python 桌面应用**。本站提供源码分享，不托管 B站账号，也不提供在线演示。

## 能做什么

- **按规则分类**：结合 UP 主映射、标签、分区和标题关键词，把收藏整理成更容易查找的结构。
- **先预览再整理**：先看分类计划，调整规则，再决定是否执行。正式整理会改动真实收藏夹，请逐项确认。
- **可选 AI 辅助**：支持 DeepSeek 辅助分类、标题清理与摘要。不填 API Key 也可以使用规则分类。
- **电脑操作，手机查看**：电脑端使用 CustomTkinter；手机网页由自己的电脑在局域网提供，不是本站的公共服务。

## 下载后怎么运行

建议 Windows 10/11，安装 Python 3.10 或更高版本。解压后进入 `bilibili-fav-classifier` 目录，在终端执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m playwright install chromium
.\.venv\Scripts\python.exe launcher.py
```

依赖和 Chromium 首次安装需要联网。启动后先用“预览分类”，扫码登录自己的账号，再检查结果、调整规则。不要把“一键分类”当成只读操作。

包内保留了核心逻辑、桌面界面、必要图标、测试及 MIT 许可证；不包含虚拟环境、浏览器缓存或 EXE。更完整的目录与测试说明见解压后的 `README.md`。

## 使用前知道这几件事

“本地规则”只表示分类计算不依赖 AI；登录、获取收藏和移动视频仍需联网，并受平台接口与规则限制。遇到限制时停止检查，不要尝试绕过访问控制。

AI 模式会把视频标题、UP 主、标签等文本发送给配置的模型服务，可能产生费用。不要分享运行后生成的配置、Cookie、收藏记录、API Key 或个人 UP 主映射。手机访问仅限可信 Wi-Fi，不要把服务端口开放到公网。

这是一份 **2026-10-20 源码整理快照**，不是新的兼容性承诺。离线测试不等同于真实账号端到端验证；平台更新可能使采集或整理失效。
