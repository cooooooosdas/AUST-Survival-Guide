# 安理大生存指南 — 网站介绍

> 写给学弟学妹们的一封信：这个网站是怎么来的、用什么做的、能帮你什么。

**在线访问：[aust.asia](https://aust.asia)**

---

## 一、这是什么网站？

「安理大生存指南」（AUST Survival Guide）是一个专门为**安徽理工大学新生**打造的一站式资源导航站。

你可能刚拿到录取通知书，对学校还一无所知——在哪选课、怎么连校园网、图书馆怎么用、高数该跟谁学、AI 工具怎么选……这些问题，这个网站试图帮你一次性解决。

它包含三大核心内容：

- **学长来信**：几篇亲笔长文，从「开学第一周该做什么」到「大学四年避坑指南」，再到「怎么把 AI 变成你的家教」，都是学长学姐踩过坑之后写出来的经验。
- **资源导航**：工具、软件、学习资料、AI 工具、学校微服务入口，按板块分类整理，点击直达。
- **社区互动**：留言板、匿名提问、FAQ、打卡学习——你不是一个人在探索。

## 三、用了什么技术？

### 整体框架

| 技术 | 说明 |
|------|------|
| **Next.js 16** | 主框架，React 的全栈 Web 框架，负责页面渲染和 API 路由 |
| **React 19** | UI 组件库 |
| **TypeScript** | 类型安全的 JavaScript，保证代码质量 |
| **Tailwind CSS v4** | 样式框架，用 utility class 写样式，不用手写 CSS 文件 |
| **Supabase** | 后端服务（数据库 + 用户认证 + 文件存储），替代传统后端服务器 |
| **Vercel** | 部署平台，代码 push 之后自动发布上线 |

简单说就是：**前端用 Next.js + React，后端数据和认证用 Supabase，部署在 Vercel**。

### 内容怎么管理？

网站上的长文（学长来信）不是写死在代码里的，而是用 **MDX** 格式写的——你可以理解为「带插件功能的 Markdown」：

- 用 Markdown 写正文（标题、列表、链接、代码块）
- 可以嵌入 React 组件（比如 `<Aside>` 提示框、`<Takeaways>` 要点总结）
- 自动生成目录、阅读进度条、阅读时间估算
- 支持脚注、表格、GFM 语法

这样写文章就像写文档一样方便，但效果比纯文档丰富得多。

### 存储方案

- **链接数据**：直接用 TypeScript 文件管理（`content/links/*.ts`），方便维护
- **学长来信**：MDX 文件（`content/letters/*.mdx`），每篇一个文件
- **用户数据、评论、点赞等**：Supabase PostgreSQL 数据库
- **文件下载**：Supabase Storage 对象存储

## 四、前后端是怎么分工的？

### 前端（浏览器端）

- **页面路由**：Next.js App Router，每个 URL 对应一个页面
- **静态生成**：大部分页面在构建时生成好 HTML，访问速度快
- **客户端交互**：点赞、收藏、评论、AI 聊天、暗色模式等动态功能用 React 客户端组件
- **UI 设计**：毛玻璃卡片（Glassmorphism）、滚动动画、三套主题色、暗色模式、响应式布局（手机/平板/电脑都适配）

### 后端（服务端）

不需要自己搭服务器。后端逻辑通过 Next.js 的 **API Routes** 实现：

```
/api/chat       → AI 助手对话
/api/comments   → 留言板 CRUD
/api/search     → 全文搜索
/api/faq        → 常见问题管理
/api/checkin    → 每日打卡
/api/favorite   → 收藏功能
/api/like       → 点赞功能
/api/resources  → 资源下载
/api/admin/*    → 管理后台
```

这些 API 路由运行在 Vercel 的 Edge 网络上，访问速度很快。

### AI 功能

网站内置了一个 AI 助手，工作原理是：

1. 先把网站所有内容（来信、资源、FAQ）转换成**向量嵌入**（embedding），存在本地文件里
2. 当用户提问时，先在本地向量库中做**语义搜索**，找到最相关的片段
3. 把相关片段作为上下文发给 AI 模型，生成回答
4. 如果本地搜索没找到答案，AI 会给出兜底回复

这个方案的好处是：**即使没有配置 AI API Key，搜索功能依然能用**。

## 五、有什么功能模块？

### 1. 学长来信
- 4 篇已发布的长文，用 MDX 编写
- 自定义组件：Aside 提示框、Takeaways 要点总结
- 阅读进度条、目录导航（自动高亮当前章节）
- 点赞、收藏、分享、评论

### 2. 工具箱
- AI 工具（DeepSeek、ChatGPT、Claude、Kimi 等 30+）
- 学校微服务入口（教务系统、图书馆、校园卡等）
- 学习资源、软件资源
- 每个链接支持一键复制、失效反馈

### 3. 社区
- 留言板（楼中楼回复、置顶、审核、标签）
- 匿名提问箱
- FAQ（从评论中提炼的常见问题）
- 管理员后台（审核评论、管理 FAQ、删除资源）

### 4. 互动功能
- 点赞 / 收藏 / 分享
- 阅读量统计
- 每日打卡 + 练习题
- 热门推荐排行

### 5. AI 助手
- 浮动聊天窗口
- 基于网站内容的语义搜索
- AI 流式回复（逐字显示）
- 建议链接跳转

### 6. 搜索
- 全文搜索（本地索引优先）
- 语义搜索（向量相似度匹配）
- AI fallback（本地搜索不足时调用大模型）

## 六、设计上有什么讲究？

### 视觉风格
- **毛玻璃拟态**（Glassmorphism）：半透明卡片 + 模糊背景，现代感强
- **三套主题色**：天空蓝紫、樱花粉、薄荷绿
- **暗色模式**：护眼夜读，自动跟随系统设置
- **滚动动画**：元素进入视口时淡入上浮

### 字体
- **Inter**：正文，清晰易读
- **Noto Serif SC**：中文标题，衬线体更有质感
- **Geist Mono**：代码块，等宽字体

### 无障碍
- 支持 `prefers-reduced-motion`（减少动画）
- 支持高对比度模式
- 键盘导航友好
- 屏幕阅读器支持

### 性能
- 静态生成，首屏加载快
- 图片懒加载
- 外部资源预连接
- 安全响应头（CSP、HSTS 等）

## 七、数据库存了什么？

Supabase（PostgreSQL）里的主要表：

| 表 | 用途 |
|----|------|
| `profiles` | 用户资料 |
| `comments` | 留言（支持嵌套回复） |
| `resources` | 下载资源信息 |
| `likes` | 点赞记录 |
| `favorites` | 收藏记录 |
| `content_views` | 阅读量统计 |
| `search_logs` | 搜索记录 |
| `checkins` | 打卡记录 |
| `faq` | 常见问题 |
| `questions` | 匿名提问 |

所有数据表都开启了 **行级安全策略**（RLS），用户只能访问自己有权限的数据。
