# 二课提醒小助手 · 双端源码分享版

源码快照：2026-10-20。此包包含电脑端与 Android 端两个独立工程，没有在线演示，也不含 EXE/APK 安装包。

## 先选一个入口

- `desktop/`：Python + FastAPI，本机浏览器打开活动看板，适合电脑使用。见该目录 README。
- `android/`：Flutter / Dart Android App，适合需要自行开发或构建手机版的人。见该目录 README。

它们面向趣拓第二课堂系统，围绕活动信息聚合、画像匹配、学时筛选和提醒展开。不是学校官方应用，不保证所有学校或接口版本都适用；报名结果以官方系统为准，不包含自动代报名承诺。

电脑端和 Android 端各自保存数据，不能假定两端会自动云同步。真实登录需要用户自己的账号；没有在分享包里提供任何人的登录状态。

## 目录与分享边界

源码、空配置模板、图标、离线测试以及必要 Android 工程文件保留。运行配置、数据库、凭据密文、通知服务地址或授权码、签名私钥、`local.properties`、Gradle 缓存、构建输出、内部接口探查材料和本机专用 APK 构建脚本已排除。

后台提醒会受系统权限、省电策略和网络影响，不应依赖它保证报名成功或提醒必达。仅在有权限的学校系统中使用，不要公开暴露本地服务。学习调试请先用演示数据，不要高频请求真实接口。
